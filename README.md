# 🎾 Теннисные турниры

Веб-приложение для тренера и родителей: группы, счёт по геймам, автоматические таблицы, плей-офф, история турниров и рейтинг сезона.

- **Родители** открывают ссылку и видят всё без входа. Результаты обновляются сами, без перезагрузки страницы.
- **Тренер и второй админ** входят по почте и паролю: создают турниры, добавляют игроков, вводят счёт.

Стек: React 19 + TypeScript + Vite + Tailwind 4, Firebase (Firestore + Authentication). Хостинг — Netlify или Firebase Hosting. Всё укладывается в бесплатные лимиты.

## Что умеет

| Раздел | Что внутри |
|---|---|
| Турниры | Список по сезонам, статус, победитель |
| Турнир → Группы | Таблицы: И, В, П, геймы, разница, место. Подсветка тех, кто выходит в плей-офф |
| Турнир → Матчи | Все матчи группового этапа. Тренер вводит два числа, сохраняется само |
| Турнир → Плей-офф | Полуфиналы, финал, матч за 3 место. Пары строятся автоматически |
| Турнир → Итоги | Итоговые места 1…N, В–П, геймы, очки рейтинга |
| Рейтинг | Сумма очков за завершённые турниры сезона |
| Игроки | Список, карточка игрока с историей всех турниров и матчей |

**Правила — как в вашем Excel:**
- место в группе: победы → разница геймов → выигранные геймы → порядок в списке группы;
- ничья не допускается;
- 2 группы → полуфиналы A1–B2 и B1–A2;
- 3 группы → победители групп + лучший второй (лучший победитель не встречается в полуфинале с игроком из своей же группы);
- 1 группа → круговой турнир без плей-офф;
- в группе от 2 до 6 игроков.

**Итоговые места:** 1–4 места определяет плей-офф, остальные — место в группе, затем показатели.

**Очки рейтинга** задаются в `src/lib/results.ts`:
```ts
export const RATING_POINTS = [100, 70, 50, 40, 25, 20, 15, 12, 10, 8, 6, 4];
export const PARTICIPATION_POINTS = 2; // всем ниже 12 места
```
Поменяйте числа как удобно клубу, и рейтинг пересчитается для всех турниров.

## Запуск: пошагово (≈ 20 минут, один раз)

Нужен Node.js 24+ (Firebase SDK 13 рассчитан на него; на 22 тоже собирается, но с предупреждениями).

### 1. Создать проект Firebase
1. Откройте https://console.firebase.google.com → **Add project**. Google Analytics не нужен.
2. Остаётся бесплатный план **Spark**, карта не требуется.

### 2. Включить вход по почте
**Build → Authentication → Get started → Sign-in method → Email/Password → Enable.**

Затем **Users → Add user**: создайте двух пользователей — себя (тренер) и второго админа.

### 3. Создать базу
**Build → Firestore Database → Create database**
- регион: `eur3 (europe-west)` — ближе к Черногории;
- режим: **production** (правила загрузим на шаге 5).

### 4. Подключить сайт к проекту
1. **Project settings (⚙️) → General → Your apps → Web (</>)** → любое имя → **Register**.
2. Скопируйте значения из `firebaseConfig`.
3. В папке проекта:
   ```bash
   cp .env.example .env.local
   ```
   и вставьте значения в `.env.local`.

### 5. Загрузить правила доступа
Проще всего через консоль: **Firestore → Rules** → вставьте содержимое файла `firestore.rules` → **Publish**.

Или через CLI:
```bash
npm i -g firebase-tools
firebase login
firebase use --add            # выбрать свой проект
firebase deploy --only firestore:rules
```

### 6. Назначить админов
1. Запустите сайт локально:
   ```bash
   npm install
   npm run dev
   ```
2. Откройте http://localhost:5173/login и войдите под тренером. Появится экран «Нет прав тренера» с длинным **ID** — скопируйте его.
3. В консоли: **Firestore → Start collection** → ID коллекции `admins` → Document ID = скопированный ID → добавьте любое поле, например `name: "Тренер"` → Save.
4. Обновите страницу — появится плашка «тренер» и кнопка «Новый турнир».
5. Повторите для второго админа.

Добавлять и удалять админов можно только в консоли Firebase: через сайт права не выдаются.

### 7. Выложить в интернет

**Вариант А — Netlify**
1. Залейте проект на GitHub (файл `.env.local` в репозиторий не попадёт, он в `.gitignore`).
2. Netlify → **Add new site → Import from Git** → выберите репозиторий. Команда сборки и папка уже указаны в `netlify.toml`.
3. **Site configuration → Environment variables**: добавьте все шесть `VITE_FIREBASE_…` из `.env.local`.
4. Deploy.
5. Firebase → **Authentication → Settings → Authorized domains → Add domain** → `ваш-сайт.netlify.app`, иначе вход на сайте не заработает.

**Вариант Б — Firebase Hosting** (домен `проект.web.app` добавляется в разрешённые автоматически)
```bash
npm run build
firebase deploy --only hosting
```

Ссылку на сайт отправляете родителям, а `/login` используете сами.

## Как проходит турнир

1. **Игроки → Добавить** — один раз заводите всех детей. Новых можно добавлять и прямо при создании турнира.
2. **Новый турнир** → название, дата, сезон, число групп → раскладываете игроков по группам (или кнопка 🎲 «Перемешать»). Расписание матчей создаётся автоматически.
3. **Матчи** → вводите геймы. Таблицы обновляются у всех сразу.
4. Когда сыграны все групповые матчи → **Начать плей-офф**. Полуфинальные пары фиксируются.
5. Вводите счёт полуфиналов → финал и матч за 3 место заполняются сами.
6. **Завершить турнир** → места и очки попадают в рейтинг сезона.

Ошиблись? «Отменить плей-офф» снова открывает групповой этап, «Открыть для исправлений» возвращает завершённый турнир в работу.

## Безопасность и приватность

- Читать данные может любой, у кого есть ссылка. Писать — только пользователи из коллекции `admins` (проверяется на сервере Firebase правилами `firestore.rules`, а не только в интерфейсе).
- Это детские данные, поэтому храните имя и первую букву фамилии, без фото и контактов.
- Если нужно, чтобы смотреть могли только свои: в `firestore.rules` замените `allow read: if true;` на `allow read: if request.auth != null;` и выдайте родителям общий логин. Скажите — доработаю.

## Бесплатные лимиты Firebase (план Spark)

50 000 чтений и 20 000 записей в день, 1 ГБ данных. Один турнир — один документ, поэтому даже 100 родителей, открывших сайт в день турнира, используют несколько процентов лимита.

## Для разработки

```bash
npm run dev     # локальный сервер
npm test        # тесты логики (проверены на данных из Excel-примера)
npm run build   # сборка в dist/
```

Локально без интернета (нужны Java и `firebase-tools`): в `.env.local` поставьте `VITE_USE_EMULATOR=true`, затем
```bash
firebase emulators:start --only auth,firestore --project demo-tennis
```

### Структура
```
src/
  types.ts              модель данных
  firebase.ts           подключение Firebase
  api.ts                все записи в базу
  hooks/data.tsx        живая подписка на игроков и турниры, статус админа
  lib/standings.ts      таблицы групп, расписание «каждый с каждым»
  lib/playoff.ts        посев полуфиналов, сетка
  lib/results.ts        итоговые места, очки рейтинга, рейтинг сезона
  lib/logic.test.ts     тесты на данных из Excel
  components/           шапка, ввод счёта, таблица группы, строка матча
  pages/                Турниры, Турнир, Новый турнир, Игроки, Игрок, Рейтинг, Вход
```

### Данные в Firestore
```
admins/{uid}            пустой документ = права тренера
players/{id}            { name, birthYear, createdAt }
tournaments/{id}        { name, date, season, status, groups, matches, playoff, playerNames, createdAt }
```
`playerNames` хранит имена на момент турнира, поэтому история не ломается, если игрока переименовали или удалили.
